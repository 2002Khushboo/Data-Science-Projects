# 🚀 Data Science & Machine Learning Projects in Python

This repository is a curated portfolio of **Data Science and Machine Learning projects** built using Python, SQL, and Jupyter Notebooks.  
Each project is based on real-world datasets and follows a structured workflow including **data preprocessing, exploratory data analysis (EDA), modeling, and evaluation**.

## 🧠 Skills & Tools Used
- Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn)
- SQL (SQLite)
- Machine Learning (Regression, Classification)
- Natural Language Processing (NLP)
- Data Visualization
- Exploratory Data Analysis (EDA)
